# acecloud_lb_pool_member (Resource)

Manages an Ace Cloud Load Balancer Pool Member (backend server).

## Example Usage

```terraform
resource "acecloud_lb_pool_member" "backend1" {
  pool_id       = acecloud_lb_pool.http.id
  address       = "10.0.0.10"
  protocol_port = 8080
  name          = "backend-1"
  weight        = 1
}

resource "acecloud_lb_pool_member" "backend2" {
  pool_id       = acecloud_lb_pool.http.id
  address       = "10.0.0.11"
  protocol_port = 8080
  name          = "backend-2"
  weight        = 1
}
```

## Schema

### Required

- `address` (String) IP address of the backend server.
- `pool_id` (String) ID of the pool this member belongs to.
- `protocol_port` (Number) Port number of the backend server (1-65535).

### Optional

- `monitor_address` (String) IP address used for health monitoring.
- `monitor_port` (Number) Port used for health monitoring (1-65535).
- `name` (String) Name of the pool member.
- `weight` (Number) Weight of the member for load balancing. Defaults to 1.

### Read-Only

- `admin_state_up` (Boolean) Administrative state of the member.
- `created_at` (String) Timestamp when the member was created.
- `id` (String) Unique identifier of the pool member.
- `operating_status` (String) Runtime health of the pool member, independent of provisioning. Values: `ONLINE` (responding to health checks), `OFFLINE` (administratively disabled or unreachable), `DEGRADED`, `DRAINING` (gracefully removed from rotation), `NO_MONITOR` (no health monitor attached to the pool).
- `provisioning_status` (String) Provisioning state of the pool member (create/update/delete lifecycle). Values: `PENDING_CREATE`, `ACTIVE`, `PENDING_UPDATE`, `PENDING_DELETE`, `ERROR`. Terraform waits until this reaches `ACTIVE` before declaring the resource ready.
