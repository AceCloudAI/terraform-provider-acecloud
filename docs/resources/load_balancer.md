# acecloud_load_balancer (Resource)

Manages an Ace Cloud Load Balancer.

## Example Usage

```terraform
resource "acecloud_vpc" "main" {
  name              = "lb-vpc"
  description       = "VPC for load balancer example"
  admin_state_up    = true
  subnet_name       = "lb-subnet"
  subnet_cidr       = "10.20.0.0/24"
  subnet_ip_version = 4
}

resource "acecloud_load_balancer" "main" {
  name        = "app-lb"
  description = "Application load balancer for web tier"
  subnet_id   = acecloud_vpc.main.subnet_id
  tags        = ["ALB"]
}
```

## Schema

### Required

- `name` (String) Name of the load balancer. Must be alphanumeric with hyphens.
- `subnet_id` (String) ID of the subnet for the load balancer VIP.
- `tags` (List of String) Tags for the load balancer. Must include exactly one of: ALB, NLB.

### Optional

- `description` (String) Human-readable description of the load balancer.

### Read-Only

- `created_at` (String) Timestamp when the load balancer was created.
- `id` (String) Unique identifier of the load balancer.
- `operating_status` (String) Runtime health of the load balancer, independent of provisioning. Values: `ONLINE` (healthy), `OFFLINE` (administratively disabled or unreachable), `DEGRADED` (partially healthy), `DRAINING` (gracefully removing members), `NO_MONITOR` (no health monitor attached).
- `provider_name` (String) Load balancer backend provider name.
- `provisioning_status` (String) Provisioning state of the load balancer (create/update/delete lifecycle). Values: `PENDING_CREATE`, `ACTIVE`, `PENDING_UPDATE`, `PENDING_DELETE`, `ERROR`. Terraform waits until this reaches `ACTIVE` before declaring the resource ready.
- `updated_at` (String) Timestamp when the load balancer was last updated.
- `vip_address` (String) Virtual IP address of the load balancer.
- `vip_network_id` (String) Network ID of the VIP.
- `vip_port_id` (String) Port ID of the VIP.
