## v0.1.2 — Security patch

**Released**: 2026-11-26
**Compatibility**: Drop-in replacement for v0.1.1. No schema changes, no state migration, no behaviour changes.

### Highlights

- Fixes 11 known vulnerabilities in third-party Go dependencies compiled into the provider binary
- Release binaries are now built with Go 1.26.11, which includes the latest standard-library security fixes (HTTP/2, TLS, URL parsing)
- `govulncheck` reports no known vulnerabilities in this release

### Security fixes

| Dependency | Previous | Now | Advisories fixed |
| --- | --- | --- | --- |
| `golang.org/x/net` | v0.52.0 | v0.62.0 | CVE-2026-39821, CVE-2026-78663, CVE-2026-33814, CVE-2026-78659, CVE-2026-78660, CVE-2026-78669, CVE-2026-97032 |
| `google.golang.org/grpc` | v1.79.3 | v1.83.2 | CVE-2026-84445, CVE-2026-84304, GHSA-hrxh-6v49-42gf |
| `golang.org/x/text` | v0.36.0 | v0.43.0 | CVE-2026-56852 |
| Go toolchain | 1.25.8 | 1.26.11 | Go standard library advisories fixed up to Go 1.26.11 |

### Upgrade

```hcl
terraform {
  required_providers {
    acecloud = {
      source  = "AceCloudAI/acecloud"
      version = "~> 0.1.2"   # was "~> 0.1.1"
    }
  }
}
```

Then `terraform init -upgrade`. No state migration required.

Building the provider from source now requires Go 1.26 or later; the Go command downloads 1.26.11 automatically when needed.
